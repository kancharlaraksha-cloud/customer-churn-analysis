Data cleaning applied

9 of 21 original columns had missing values, ranging from 4.2% (Gender) to 83.1% (SubtitlesEnabled). Numeric billing fields (MonthlyCharges, TotalCharges) were imputed with the median grouped by subscription plan; UserRating was imputed with the median grouped by content type, alongside a "RatingGiven" flag so missingness itself stays analyzable. Low-cardinality categorical fields were imputed by mode or labeled "Unknown" / "Not Recorded" rather than guessed, to avoid biasing payment-method and demographic analysis.

Correction made for this dashboard: three derived fields in the originally supplied workbook (UserRating, SatisfactionBand, SupportLoadBand) contained a data-processing error — UserRating had been overwritten with a constant placeholder value for every row, which cascaded into a degenerate SatisfactionBand. These three fields were recomputed from the original raw values before building this dashboard so the analysis reflects real customer ratings and support-load segments.

Analysis & methodology

This dashboard presents a descriptive and exploratory analysis of customer churn. It examines how churn varies across subscription, billing, tenure, engagement, viewing behaviour, support activity, satisfaction and customer-profile segments.

Approach
Descriptive and exploratory analytics
Target variable
Churn (1 = churned, 0 = retained)
Analysis areas
Subscription, engagement, behaviour and customer profile
Segmentation
Tenure, engagement, support load, satisfaction and value tiers
Visualization
Churn rates and customer distributions by segment

Limitations

The dashboard identifies observed patterns and associations in the dataset. These relationships should not be interpreted as proof that a particular factor causes churn.
